# Travego SQL Project

## Project Overview
This project is based on a travel management database system named **Travego**.  
The project stores passenger details and bus ticket pricing information using MySQL.

The main objective of this project is to perform different SQL operations such as:
- Database creation
- Table creation
- Data insertion
- Data retrieval
- Data analysis
- Updating records
- Deleting records

---

## Technologies Used
- MySQL
- SQL
- MySQL Workbench

---

```sql
travego
````

## Tables Used

### 1. Passenger Table

Stores passenger travel information.

Columns:

* Passenger ID
* Passenger Name
* Category
* Gender
* Boarding City
* Destination City
* Distance
* Bus Type

---

### 2. Price Table

Stores bus ticket pricing details.

Columns:

* ID
* Bus Type
* Distance
* Price
